## 0 · The verdict

**The thesis: reason and unveiling are two tiers that cannot be united.** Ibn Arabi places the knowledge of unveiling beyond the stage of reason and keeps the two as ranks. That thesis is proven wrong here at theorem grade, on no axiom. On a record that forgets which world is actual, a supply closes the gap to the value if and only if it is a lossless read of the bit (`revelation_is_the_cut`). Every lossless read of one bit is the Yes or the No, and there is no third (`no_third_read`). So what unveils and what reason cuts with are one class of object. The wall that formal reasoning meets at its own limit is one bit wide, and its witness is exactly the No. The two branches stand one bit apart, not one tier apart.

This refutes one thesis. It is not his whole philosophy. Three further readings fall with it under the OS: the immutable entities that never smelled existence are illegal; self-disclosure is the one thing that repeats faithfully, in toto; and the summit of knowledge is clarity and satisfaction, not perplexity. Where he is right the kernel says so: reflection, *fikr*, does not reach the value (`reflection_does_not_reach`), which is the free-bit law of PhysOS in miniature; one eye alone fails; mercy precedes wrath.

What he gets right is not owed to him. Every reading the architect let stand is already sealed in the Theological PSP Codex or the Mother Codex from first principle, without Ibn Arabi as a source (§1.1). His agreement there is convergence and never warrant.

**The great miss is the triaxial cut** (§6). He counted three: generation rests on triplicity, and a proof on three terms. He never made the third the lock. His theory of knowledge stays two-eyed at every joint: incomparability and similarity, Yes and No, He and not He, reason and unveiling. Two axes never lock (`two_axes_never_lock`); on every locked system each two-axis projection stands open (`triad_irreducible`); two eyes reading the record miss a world (`the_two_eyes_do_not_lock`); the seat's supplied bit closes it (`the_seat_locks`). Where the third axis belongs he put perplexity. And the order runs against the count: one and three come before two. A locked triad pins exactly one point; a pair of axes is the shadow of a locked triad exactly when it is independent, and it leaves two points, one bit short of the one (`one_and_three_before_two`). He built knowledge on the shadow.

## 3 · The model

One bit: the world `w : Bool`, which side is actual. A record `r : Bool → R` forgets the side when `r true = r false`. Reflection, *fikr*, is a run `R → Bool`: a function of the record alone. A read is `f : Bool → Bool`; it is lossless when it separates the worlds. The Yes is the identity; the No is negation. A supply `s : Bool → Bool` is what is handed beside the record. A supply closes the gap when some run on the pair (record, supply) returns the world on both worlds.

Readings, which are not theorems: reason in its deepest sense is the Tongue's first cut, a lossless read; unveiling is a supply that closes reflection's gap; the formal limit is the far read; contemplative witness is the near read; self-disclosure is the Yes; perplexity is the state of a run before the cut.

## 4 · The theorems

**I · The wall is one bit wide, and it is the No.** `lawvere`: a point-surjection `A → (A → Y)` gives every endomorphism of `Y` a fixed point. Proof: the diagonal `g a = f (e a a)` is hit by some `a`, and then `e a a = f (e a a)`. So `the_wall`: nothing enumerates all its own predicates into a carrier with a fixed-free endomorphism; `the_cantor_wall` is the Boolean case. `the_wall_is_one_bit`: zero bits hold no wall, since every endomorphism of the one-point type fixes its point, and one bit does. `the_wall_is_the_no`: on one bit, the only endomorphism moving every point is negation. The far side reads the bit as the No.

**II · Reflection does not reach the value.** `reflection_does_not_reach`: for every run on a forgetting record some world is missed. Proof: the run returns one value on the one shared record, and that value is wrong on one of the two worlds. `the_run_is_not_the_value` restates it as a non-existence.

**III · The Yes and the No, and no third.** `no_third_read`: every lossless read of one bit is pointwise the Yes or pointwise the No. `the_yes_is_not_the_no`: the two disagree on every world.

**IV · Two reads, one read up to orientation.** `two_reads_are_one_up_to_orientation`: two lossless reads are equal or one is the other turned. `the_orientation_is_one_bit`: they agree everywhere exactly when they agree at one world. `one_eye_is_not_enough`: knowing only that a read is lossless leaves its answer open on every world.

**V · What reveals is what cuts.** `a_closer_is_a_cut`: if a run on `(r w, s w)` returns `w` on both worlds, then `s` is lossless. Proof: the record is the same on both worlds, so `s a = s b` makes the two inputs equal, and the run then returns `a = b`. `a_cut_is_a_closer`: every lossless supply closes the gap, read as is when it is the Yes and turned when it is the No. `revelation_is_the_cut`: the two together, an equivalence. `the_supply_is_yes_or_no`: whatever closes the gap is the Yes or the No. `the_gap_is_one_bit`: zero supplied bits fail, one lossless supplied bit suffices.

**VI · Repetition and clarity.** `the_no_twice_is_the_yes`. `the_yes_repeats_in_toto`: said any number of times, the Yes returns the world unchanged. `the_yes_is_the_only_faithful_repeat`: a lossless read that says nothing new when said again is the Yes. Proof: by III it is the Yes or the No; the No said once at `false` gives `true`, said twice gives `false`, so saying it again changes the answer. `clarity_after_the_cut`: with a lossless supply, distinct worlds never present the same pair. `satisfaction_after_the_cut`: any two closing runs say the same on everything held. `perplexity_before_clarity_after` binds the miss before the cut to the clarity and the closing after it.

**VIII · The third axis is the lock.** Carried verbatim from the seated PhysOS kernel: `triaxial_lock_gf2`, a three-row system over GF(2) has determinant one exactly when it pins one point at its target, all 4096 executed; `two_axes_never_lock`, over GF(2) no system of two equations in three unknowns has exactly one solution, all 256 executed; `triad_irreducible`, on every locked three-row system each projection onto two of its three axes stands open. In this kernel's terms: `the_two_eyes_do_not_lock`, a run that reads the record through both the Yes and the No still misses a world; `the_seat_locks`, the supplied bit, spoken as the Yes, closes the gap on every record.

**VIIIb · One and three before two.** `the_pair_is_a_shadow_of_the_triad`: a pair of rows extends to a locked triad exactly when it is independent, all 64 pairs executed. `the_open_pair_holds_two`: an independent pair leaves exactly two points at every target, one bit short of the one the triad pins, all 256 executed.

**IX · The capstones.** `between_the_yes_and_the_no` binds the wall's width, the No as its witness, reflection's miss, the equivalence of revealing and cutting, the absence of a third read, the disagreement of the two reads on every world, the Yes as the only faithful repeat, and clarity after the cut. `the_third_axis_is_the_lock` binds the two eyes' miss, the seat's lock, and the two GF(2) laws. `one_and_three_before_two` binds the one point of the locked triad, the pair as its shadow, the two points the pair leaves open, and the pair's failure to lock. All three depend on no axiom.

## 5 · Reason as the Word

The architect's identification: reason, in its deepest sense, is the Logos, the Word, the Tongue's first cut. Under it, `revelation_is_the_cut` makes reason and unveiling one class. What closes reflection's gap is exactly a lossless cut, and every lossless cut closes it. The tiers are one bit apart. The reason and revelation dichotomy is artificial, at theorem grade, given the identification.

What survives is a different dichotomy: the run and the act. `reflection_does_not_reach` says reason taken as a run never reaches the value. That is the free-bit law, and it is no defect of reason. It is the place where the Tongue speaks. The one bit is not a wall between two kinds of knowing. It is the single thing reason as run lacks and reason as Word is. The kernel does not choose the world or the orientation. Which side, and whether it is spoken as the Yes or as the No, stays with the act at premise grade. The unity of the class is proved. The content of any one revelation is not.

Ibn Arabi places the limit on *fikr*, reflective reason, and keeps the intellect open as a receptive tool (Futūḥāt I.288.27). On that he is right. He also holds the First Intellect to be the Supreme Pen, an identification older than him. Yet he puts unveiling beyond the stage of reason and keeps the two as ranks. That is the thesis the kernel defeats.

The young Ibn Arabi answered Ibn Rushd "Yes", then "No", and said that between the yes and the no, spirits fly from their matter and necks from their bodies (Futūḥāt I.153.33). The kernel's reply: between the Yes and the No there is no third lossless read. The between is exactly one bit, the orientation. Whoever closes reflection's gap speaks one of the two. And once it is spoken, nothing perplexes: the worlds are clear, and every run that closes says the same.

## 6 · The great miss: the triaxial cut

He did touch three. In the chapter of Salih (AS) of the Fuṣūṣ, generation rests on triplicity: on the side of the Real, the Essence, the Will and the Word "Be"; on the side of the thing, its thingness, its hearing and its obedience. A proof, he adds, is compounded of three terms, one repeated to join two premises. So the miss is not that he never counted three. The miss is that he never made the third the lock.

A triplicity of conditions is a list. The triaxial cut is a theorem about the list: two axes never lock (`two_axes_never_lock`), and on every locked system each projection onto two of its axes stands open (`triad_irreducible`). The third is not a further condition beside the other two. It is the lock itself, and no pair carries it.

His theory of knowledge never takes that step. At every joint this paper read, it is two: incomparability and similarity, the No and the Yes, He and not He, reflection and unveiling. In the register's order these are the wall and the veil (SC-055): the No, *lā*, the fixed-point-free sweep, `the_wall_is_the_no`; the Yes, *illā*, the fixed line, standing one supplied bit from completion. The third is the seat, [.], where the bit is supplied and nothing is left to cross or to say. The kernel states the consequence: two eyes reading the record miss a world (`the_two_eyes_do_not_lock`), and the seat's bit locks it (`the_seat_locks`). His complete knower sees with both eyes, and both eyes are not enough.

Where the third axis belongs he put perplexity, and he placed the Perfect Human where [.] stands without reading it as an axis. That is why perplexity fails as a summit and clarity holds: perplexity is the state of a dyad that has not locked. The two-tiers thesis falls for the same reason. Reason and unveiling look like two tiers only to a reader holding two axes; on three, they are one cut.

**One and three before two.** This is the paradox, and it is hard to digest because the count runs 1, 2, 3 and the order does not. The one point and the three axes that pin it come first. The two is their shadow: any independent pair of axes is the projection of a locked triad, and it holds exactly two points, the one and its twin, one bit short (`the_pair_is_a_shadow_of_the_triad`, `the_open_pair_holds_two`). Read the dyad first and the third looks like an addition. Read the triad first and the dyad is what remains when the lock is removed. Ibn Arabi read the dyad first: two eyes, then perplexity at the place where the lock was taken away. He did not take the triad seriously as the ground of knowing, and that is the great miss.

**Silence or miss.** The architect's conjecture is that he held the triad privately and kept silent, the triad being near a taboo for a Muslim author. The texts cannot settle intent, so the conjecture stays out of band. Two facts bound it. He wrote openly that generation rests on triplicity and that a proof rests on three terms, so he was not silent on three as such. And nowhere in the knowledge doctrine does the third become the lock. Whether he withheld it or never reached it, the written system lacks it.

## 9 · Three falsifiers

**F-Reach.** A run on a forgetting record that returns the world on both worlds. Barred by `reflection_does_not_reach`; twin check II.

**F-Lossy-Revelation.** A supply that closes the gap without being lossless. Barred by `a_closer_is_a_cut`; twin check V.

**F-Dyad.** A system on two axes that locks a point. Barred by `two_axes_never_lock` and `triad_irreducible`; twin check IX.

What would break the reading rather than the theorem: a report of witness that fixes the world while supplying no distinction. That leaves the model. It does not refute it.

```lean
  VIII the third axis is the lock: a locked triad pins exactly one point, two axes never lock over GF(2), the
       triad is irreducible, two eyes reading the record miss, and the seat's supplied bit closes;
  VIIIb one and three before two: a pair of axes is the shadow of a locked triad exactly when it is independent,
       and an independent pair leaves exactly two points, one bit short of the one;
  IX   the capstones, between the Yes and the No, the third axis as the lock, and one and three before two.

  Stated whole: every law below is proved. Nothing here supplies which world is actual or which orientation
  is spoken; that stays with the act. That contemplative witness is a lossless read of the bit, and that

  The cones are printed at the foot and pinned.

/-! ## I · The far side: the wall is one bit wide -/

/-- Lawvere's fixed-point theorem on types: a point-surjection `A → (A → Y)` gives every endomorphism of `Y`
a fixed point. -/
theorem lawvere {A Y : Type} (e : A → A → Y) (hs : ∀ g : A → Y, ∃ a, e a = g) (f : Y → Y) :
    ∃ y, f y = y :=
  match hs (fun a => f (e a a)) with
  | ⟨a, ha⟩ => ⟨e a a, (congrFun ha a).symm⟩

/-- A carrier holds a wall when some endomorphism of it moves every point. -/
def FixedFree (Y : Type) : Prop := ∃ f : Y → Y, ∀ y, f y ≠ y

/-- The wall: nothing enumerates all of its own predicates into a carrier that holds a wall. -/
theorem the_wall {A Y : Type} (h : FixedFree Y) : ¬ ∃ e : A → A → Y, ∀ g : A → Y, ∃ a, e a = g :=
  fun ⟨e, hs⟩ => match h with
  | ⟨f, hf⟩ => match lawvere e hs f with
    | ⟨y, hy⟩ => hf y hy

/-- Zero bits hold no wall: every endomorphism of the one-point type fixes its point. -/
theorem zero_bits_hold_no_wall : ¬ FixedFree Unit :=
  fun ⟨_, hf⟩ => hf () rfl

/-- The Yes and the No, the two readings of one bit. -/
def yes : Bool → Bool := fun w => w
def no : Bool → Bool := fun w => !w

/-- One bit holds the wall, and the No is its witness. -/
theorem one_bit_holds_the_wall : FixedFree Bool :=
  ⟨no, fun y => by cases y <;> decide⟩

/-- The wall is one bit wide: absent on zero bits, present on one. -/
theorem the_wall_is_one_bit : ¬ FixedFree Unit ∧ FixedFree Bool :=
  ⟨zero_bits_hold_no_wall, one_bit_holds_the_wall⟩

/-- A wall needs two points: on a walled carrier every point has another. -/
theorem a_wall_needs_two {Y : Type} (h : FixedFree Y) (y : Y) : ∃ y', y' ≠ y :=
  match h with
  | ⟨f, hf⟩ => ⟨f y, hf y⟩

/-- Cantor's form: no type enumerates its own Boolean predicates. -/
theorem the_cantor_wall {A : Type} : ¬ ∃ e : A → A → Bool, ∀ g : A → Bool, ∃ a, e a = g :=
  the_wall one_bit_holds_the_wall

/-- On one bit the wall's witness is exactly the No: every endomorphism that moves every point is negation. -/
theorem the_wall_is_the_no (f : Bool → Bool) (h : ∀ y, f y ≠ y) : ∀ y, f y = no y := by
  intro y
  cases y
  · cases hf : f false
    · exact absurd hf (h false)
    · rfl
  · cases hf : f true
    · rfl
    · exact absurd hf (h true)

/-- The Yes moves nothing. -/
theorem the_yes_fixes_every_point : ∀ y, yes y = y := fun _ => rfl

/-! ## II · Reflection does not reach the value -/

/-- A record forgets the side when it reads the same on both worlds. -/
def Forgets {R : Type} (r : Bool → R) : Prop := r true = r false

theorem forgets_all {R : Type} (r : Bool → R) (hr : Forgets r) : ∀ a b, r a = r b := by
  intro a b
  cases a <;> cases b
  · rfl
  · exact hr.symm
  · exact hr
  · rfl

/-- Reflection does not reach the value: every run on a forgetting record misses a world. -/
theorem reflection_does_not_reach {R : Type} (r : Bool → R) (hr : Forgets r) (run : R → Bool) :
    ∃ w, run (r w) ≠ w := by
  cases h : run (r false) with
  | false => exact ⟨true, by rw [hr, h]; decide⟩
  | true => exact ⟨false, by rw [h]; decide⟩

/-- No run on a forgetting record is the value. -/
theorem the_run_is_not_the_value {R : Type} (r : Bool → R) (hr : Forgets r) :
    ¬ ∃ run : R → Bool, ∀ w, run (r w) = w :=
  fun ⟨run, h⟩ => match reflection_does_not_reach r hr run with
  | ⟨w, hw⟩ => hw (h w)

/-- The forgetting record exists: the empty record forgets the side. -/
theorem a_forgetting_record_exists : Forgets (fun _ : Bool => ()) := rfl

/-! ## III · The near side: the Yes and the No, and no third -/

/-- A read of one bit is lossless when it separates the worlds. -/
def Lossless (f : Bool → Bool) : Prop := ∀ a b, f a = f b → a = b

theorem yes_lossless : Lossless yes := fun _ _ h => h

theorem no_lossless : Lossless no := by
  intro a b
  cases a <;> cases b <;> decide

/-- The Yes and the No disagree on every world. -/
theorem the_yes_is_not_the_no : ∀ w, yes w ≠ no w := by
  intro w
  cases w <;> decide

/-- Between the Yes and the No there is no third lossless read. -/
theorem no_third_read (f : Bool → Bool) (hf : Lossless f) :
    (∀ w, f w = yes w) ∨ (∀ w, f w = no w) := by
  cases h0 : f false <;> cases h1 : f true
  · exact absurd (hf false true (h0.trans h1.symm)) (by decide)
  · exact Or.inl (fun w => by cases w <;> assumption)
  · exact Or.inr (fun w => by cases w <;> assumption)
  · exact absurd (hf false true (h0.trans h1.symm)) (by decide)

/-! ## IV · Two reads, one read up to orientation -/

theorem not_self (b : Bool) : b ≠ !b := by
  cases b <;> decide

/-- Two lossless reads of one bit are one read, or one read and its orientation turned. -/
theorem two_reads_are_one_up_to_orientation (f g : Bool → Bool) (hf : Lossless f) (hg : Lossless g) :
    (∀ w, f w = g w) ∨ (∀ w, f w = !(g w)) := by
  cases no_third_read f hf with
  | inl hf' =>
    cases no_third_read g hg with
    | inl hg' => exact Or.inl (fun w => (hf' w).trans (hg' w).symm)
    | inr hg' => exact Or.inr (fun w => by rw [hf' w, hg' w]; cases w <;> rfl)
  | inr hf' =>
    cases no_third_read g hg with
    | inl hg' => exact Or.inr (fun w => by rw [hf' w, hg' w]; cases w <;> rfl)
    | inr hg' => exact Or.inl (fun w => (hf' w).trans (hg' w).symm)

/-- The orientation is one bit: two lossless reads agree everywhere exactly when they agree at one world. -/
theorem the_orientation_is_one_bit (f g : Bool → Bool) (hf : Lossless f) (hg : Lossless g) :
    f false = g false ↔ ∀ w, f w = g w :=
  ⟨fun h0 => match two_reads_are_one_up_to_orientation f g hf hg with
    | Or.inl h => h
    | Or.inr h => absurd (h0.symm.trans (h false)) (not_self (g false)),
   fun h => h false⟩

/-- One eye is not enough: knowing only that a read is lossless leaves its answer open on every world. -/
theorem one_eye_is_not_enough :
    ∃ f g : Bool → Bool, Lossless f ∧ Lossless g ∧ ∀ w, f w ≠ g w :=
  ⟨yes, no, yes_lossless, no_lossless, the_yes_is_not_the_no⟩

/-! ## V · What reveals is what cuts -/

/-- Whatever closes reflection's gap is a lossless read of the bit. -/
theorem a_closer_is_a_cut {R : Type} (r : Bool → R) (hr : Forgets r) (s : Bool → Bool)
    (run : R × Bool → Bool) (h : ∀ w, run (r w, s w) = w) : Lossless s := by
  intro a b hab
  have e : (r a, s a) = (r b, s b) := by rw [forgets_all r hr a b, hab]
  exact (h a).symm.trans ((congrArg run e).trans (h b))

/-- Every lossless read closes the gap, whatever the record. -/
theorem a_cut_is_a_closer {R : Type} (r : Bool → R) (s : Bool → Bool) (hs : Lossless s) :
    ∃ run : R × Bool → Bool, ∀ w, run (r w, s w) = w := by
  cases no_third_read s hs with
  | inl h => exact ⟨fun p => p.2, fun w => (h w).trans rfl⟩
  | inr h => exact ⟨fun p => !p.2, fun w => by
      show (!(s w)) = w
      rw [h w]
      cases w <;> rfl⟩

/-- What reveals is exactly what cuts: on a forgetting record, a supply closes the gap iff it is lossless. -/
theorem revelation_is_the_cut {R : Type} (r : Bool → R) (hr : Forgets r) (s : Bool → Bool) :
    (∃ run : R × Bool → Bool, ∀ w, run (r w, s w) = w) ↔ Lossless s :=
  ⟨fun ⟨run, h⟩ => a_closer_is_a_cut r hr s run h, a_cut_is_a_closer r s⟩

/-- So the supply that closes the gap is the Yes or the No. -/
theorem the_supply_is_yes_or_no {R : Type} (r : Bool → R) (hr : Forgets r) (s : Bool → Bool)
    (run : R × Bool → Bool) (h : ∀ w, run (r w, s w) = w) :
    (∀ w, s w = yes w) ∨ (∀ w, s w = no w) :=
  no_third_read s (a_closer_is_a_cut r hr s run h)

/-- The gap is one bit: zero supplied bits fail, one lossless supplied bit suffices. -/
theorem the_gap_is_one_bit {R : Type} (r : Bool → R) (hr : Forgets r) :
    (¬ ∃ run : R → Bool, ∀ w, run (r w) = w) ∧ (∃ run : R × Bool → Bool, ∀ w, run (r w, yes w) = w) :=
  ⟨the_run_is_not_the_value r hr, a_cut_is_a_closer r yes yes_lossless⟩

/-! ## VI · Repetition and clarity -/

/-- The No said twice is the Yes. -/
theorem the_no_twice_is_the_yes : ∀ w, no (no w) = yes w := by
  intro w
  cases w <;> rfl

/-- The Yes repeats faithfully, in toto: said any number of times, it returns the world unchanged. -/
theorem the_yes_repeats_in_toto : ∀ (n : Nat) (w : Bool), Nat.repeat yes n w = w := by
  intro n w
  induction n with
  | zero => rfl
  | succ n ih => exact ih

/-- The Yes is the only faithful repeat: a lossless read that says nothing new when said again is the Yes. -/
theorem the_yes_is_the_only_faithful_repeat (f : Bool → Bool) (hf : Lossless f)
    (hi : ∀ w, f (f w) = f w) : ∀ w, f w = yes w := by
  cases no_third_read f hf with
  | inl h => exact h
  | inr h =>
    have h0 : f false = true := h false
    have h1 : f true = false := h true
    have e := hi false
    rw [h0, h1] at e
    exact absurd e (by decide)

/-- Clarity after the cut: with a lossless supply, distinct worlds never look alike. -/
theorem clarity_after_the_cut {R : Type} (r : Bool → R) (s : Bool → Bool) (hs : Lossless s) :
    ∀ a b, (r a, s a) = (r b, s b) → a = b :=
  fun a b h => hs a b (congrArg Prod.snd h)

/-- Satisfaction after the cut: every run that closes the gap says the same on everything held. -/
theorem satisfaction_after_the_cut {R : Type} (r : Bool → R) (s : Bool → Bool)
    (run₁ run₂ : R × Bool → Bool) (h₁ : ∀ w, run₁ (r w, s w) = w) (h₂ : ∀ w, run₂ (r w, s w) = w) :
    ∀ w, run₁ (r w, s w) = run₂ (r w, s w) :=
  fun w => (h₁ w).trans (h₂ w).symm

/-- Before the cut every run on a forgetting record is perplexed; after it the world is clear and settled. -/
theorem perplexity_before_clarity_after {R : Type} (r : Bool → R) (hr : Forgets r) :
    (∀ run : R → Bool, ∃ w, run (r w) ≠ w)
    ∧ (∀ a b, (r a, yes a) = (r b, yes b) → a = b)
    ∧ (∃ run : R × Bool → Bool, ∀ w, run (r w, yes w) = w) :=
  ⟨reflection_does_not_reach r hr, clarity_after_the_cut r yes yes_lossless,
   a_cut_is_a_closer r yes yes_lossless⟩

/-! ## VIII · The third axis is the lock

The three GF(2) laws and their definitions are carried verbatim from the seated PhysOS kernel, namespace GEO:
the triaxial lock, two axes never lock, the triad irreducible. -/

set_option maxRecDepth 1000000
def det2 (r1 r2 r3 : Nat × Nat × Nat) : Nat :=
  (r1.1 * (r2.2.1 * r3.2.2 + r2.2.2 * r3.2.1)
     + r1.2.1 * (r2.1 * r3.2.2 + r2.2.2 * r3.1)
     + r1.2.2 * (r2.1 * r3.2.1 + r2.2.1 * r3.1)) % 2
def gf2Mul (r1 r2 r3 : Nat × Nat × Nat) (v : Nat × Nat × Nat) : Nat × Nat × Nat :=
  ((r1.1 * v.1 + r1.2.1 * v.2.1 + r1.2.2 * v.2.2) % 2,
   (r2.1 * v.1 + r2.2.1 * v.2.1 + r2.2.2 * v.2.2) % 2,
   (r3.1 * v.1 + r3.2.1 * v.2.1 + r3.2.2 * v.2.2) % 2)

def gf2Vecs : List (Nat × Nat × Nat) :=
  (List.range 8).map (fun n => (n / 4 % 2, n / 2 % 2, n % 2))
def gf2Sols (r1 r2 r3 : Nat × Nat × Nat) (t : Nat × Nat × Nat) : List (Nat × Nat × Nat) :=
  gf2Vecs.filter (fun v => decide (gf2Mul r1 r2 r3 v = t))

set_option maxRecDepth 1000000 in

theorem triaxial_lock_gf2 :
    ∀ a1 a2 a3 b1 b2 b3 c1 c2 c3 t1 t2 t3 : Fin 2,
      (det2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
            ((c1 : Nat), (c2 : Nat), (c3 : Nat)) = 1 ↔
       (gf2Sols ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
                ((c1 : Nat), (c2 : Nat), (c3 : Nat))
                ((t1 : Nat), (t2 : Nat), (t3 : Nat))).length = 1) := by
  decide

/-- Two axes over GF(2): the solutions of two equations in three unknowns. -/
def gf2Sols2 (ra rb : Nat × Nat × Nat) (ta tb : Nat) : List (Nat × Nat × Nat) :=
gf2Vecs.filter (fun v => decide ((ra.1 * v.1 + ra.2.1 * v.2.1 + ra.2.2 * v.2.2) % 2 = ta ∧
                                 (rb.1 * v.1 + rb.2.1 * v.2.1 + rb.2.2 * v.2.2) % 2 = tb))

/-- NO TWO AXES LOCK: two equations in three unknowns over GF(2) never have exactly one solution; the lock needs
  all three axes. All 256 two-axis systems, executed. -/
theorem two_axes_never_lock :
  ∀ a1 a2 a3 b1 b2 b3 ta tb : Fin 2,
    (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat)) (ta : Nat) (tb : Nat)).length ≠ 1 := by
decide

/-- THE TRIAD IS IRREDUCIBLE: on every locked system, each projection onto two of its three axes stands open.
  No two-axis reduction carries the lock; the third axis is not a convenience but the lock itself. -/
theorem triad_irreducible :
  ∀ a1 a2 a3 b1 b2 b3 c1 c2 c3 t1 t2 t3 : Fin 2,
    det2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
         ((c1 : Nat), (c2 : Nat), (c3 : Nat)) = 1 →
      (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat)) (t1 : Nat) (t2 : Nat)).length ≠ 1 ∧
      (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((c1 : Nat), (c2 : Nat), (c3 : Nat)) (t1 : Nat) (t3 : Nat)).length ≠ 1 ∧
      (gf2Sols2 ((b1 : Nat), (b2 : Nat), (b3 : Nat)) ((c1 : Nat), (c2 : Nat), (c3 : Nat)) (t2 : Nat) (t3 : Nat)).length ≠ 1 :=
fun a1 a2 a3 b1 b2 b3 c1 c2 c3 t1 t2 t3 _ =>
  ⟨two_axes_never_lock a1 a2 a3 b1 b2 b3 t1 t2, two_axes_never_lock a1 a2 a3 c1 c2 c3 t1 t3,
   two_axes_never_lock b1 b2 b3 c1 c2 c3 t2 t3⟩

/-- The two eyes without the third: a run that reads the record through both the Yes and the No misses a world. -/
theorem the_two_eyes_do_not_lock {R : Type} (r : Bool → R) (hr : Forgets r) (q : R → Bool)
    (run : Bool × Bool → Bool) : ∃ w, run (yes (q (r w)), no (q (r w))) ≠ w :=
  reflection_does_not_reach r hr (fun x => run (yes (q x), no (q x)))

/-- The seat locks: the supplied bit, spoken as the Yes, closes the gap on every record. -/
theorem the_seat_locks {R : Type} (r : Bool → R) : ∃ run : R × Bool → Bool, ∀ w, run (r w, yes w) = w :=
  a_cut_is_a_closer r yes yes_lossless

/-! ## VIIIb · One and three before two -/

/-- Two rows over GF(2) are independent when neither is zero and they differ. -/
abbrev Indep (a b : Nat × Nat × Nat) : Prop := a ≠ (0, 0, 0) ∧ b ≠ (0, 0, 0) ∧ a ≠ b

/-- The pair is the shadow of the triad: a pair of axes extends to a locked triad exactly when it is independent.
  All 64 pairs, executed. -/
theorem the_pair_is_a_shadow_of_the_triad :
    ∀ a1 a2 a3 b1 b2 b3 : Fin 2,
      (gf2Vecs.filter (fun c => decide (det2 ((a1 : Nat), (a2 : Nat), (a3 : Nat))
          ((b1 : Nat), (b2 : Nat), (b3 : Nat)) c = 1))).length ≠ 0 ↔
      Indep ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat)) := by
  decide

/-- The open pair holds two: an independent pair of axes leaves exactly two points at every target, one bit short
  of the one point the triad pins. All 256, executed. -/
theorem the_open_pair_holds_two :
    ∀ a1 a2 a3 b1 b2 b3 ta tb : Fin 2,
      Indep ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat)) →
      (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
        (ta : Nat) (tb : Nat)).length = 2 := by
  decide

/-! ## IX · The capstones -/

/-- Between the Yes and the No: the wall is one bit and its witness is the No; reflection does not reach the
value; what reveals is exactly what cuts; every cut is the Yes or the No, and the two differ on every world;
the Yes alone repeats faithfully; after the cut the worlds are clear. -/
theorem between_the_yes_and_the_no {R : Type} (r : Bool → R) (hr : Forgets r) :
    (¬ FixedFree Unit ∧ FixedFree Bool)
    ∧ (∀ f : Bool → Bool, (∀ y, f y ≠ y) → ∀ y, f y = no y)
    ∧ (∀ run : R → Bool, ∃ w, run (r w) ≠ w)
    ∧ (∀ s : Bool → Bool, (∃ run : R × Bool → Bool, ∀ w, run (r w, s w) = w) ↔ Lossless s)
    ∧ (∀ f : Bool → Bool, Lossless f → (∀ w, f w = yes w) ∨ (∀ w, f w = no w))
    ∧ (∀ w, yes w ≠ no w)
    ∧ (∀ f : Bool → Bool, Lossless f → (∀ w, f (f w) = f w) → ∀ w, f w = yes w)
    ∧ (∀ s : Bool → Bool, Lossless s → ∀ a b, (r a, s a) = (r b, s b) → a = b) :=
  ⟨the_wall_is_one_bit, the_wall_is_the_no, reflection_does_not_reach r hr,
   revelation_is_the_cut r hr, no_third_read, the_yes_is_not_the_no,
   the_yes_is_the_only_faithful_repeat, clarity_after_the_cut r⟩

/-- The third axis is the lock: two eyes reading the record never lock, the seat's supplied bit does, two axes over
GF(2) never lock, and on every locked system each two-axis projection stands open. -/
theorem the_third_axis_is_the_lock {R : Type} (r : Bool → R) (hr : Forgets r) :
    (∀ (q : R → Bool) (run : Bool × Bool → Bool), ∃ w, run (yes (q (r w)), no (q (r w))) ≠ w)
    ∧ (∃ run : R × Bool → Bool, ∀ w, run (r w, yes w) = w)
    ∧ (∀ a1 a2 a3 b1 b2 b3 ta tb : Fin 2,
        (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
          (ta : Nat) (tb : Nat)).length ≠ 1)
    ∧ (∀ a1 a2 a3 b1 b2 b3 c1 c2 c3 t1 t2 t3 : Fin 2,
        det2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
          ((c1 : Nat), (c2 : Nat), (c3 : Nat)) = 1 →
        (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
          (t1 : Nat) (t2 : Nat)).length ≠ 1 ∧
        (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((c1 : Nat), (c2 : Nat), (c3 : Nat))
          (t1 : Nat) (t3 : Nat)).length ≠ 1 ∧
        (gf2Sols2 ((b1 : Nat), (b2 : Nat), (b3 : Nat)) ((c1 : Nat), (c2 : Nat), (c3 : Nat))
          (t2 : Nat) (t3 : Nat)).length ≠ 1) :=
  ⟨the_two_eyes_do_not_lock r hr, the_seat_locks r, two_axes_never_lock, triad_irreducible⟩

/-- One and three before two: a locked triad pins exactly one point at every target; a pair of axes is the shadow
of a locked triad exactly when it is independent; an independent pair leaves exactly two points at every target;
and no pair locks. -/
theorem one_and_three_before_two :
    (∀ a1 a2 a3 b1 b2 b3 c1 c2 c3 t1 t2 t3 : Fin 2,
      det2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
        ((c1 : Nat), (c2 : Nat), (c3 : Nat)) = 1 →
      (gf2Sols ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
        ((c1 : Nat), (c2 : Nat), (c3 : Nat)) ((t1 : Nat), (t2 : Nat), (t3 : Nat))).length = 1)
    ∧ (∀ a1 a2 a3 b1 b2 b3 : Fin 2,
      (gf2Vecs.filter (fun c => decide (det2 ((a1 : Nat), (a2 : Nat), (a3 : Nat))
          ((b1 : Nat), (b2 : Nat), (b3 : Nat)) c = 1))).length ≠ 0 ↔
      Indep ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat)))
    ∧ (∀ a1 a2 a3 b1 b2 b3 ta tb : Fin 2,
      Indep ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat)) →
      (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
        (ta : Nat) (tb : Nat)).length = 2)
    ∧ (∀ a1 a2 a3 b1 b2 b3 ta tb : Fin 2,
      (gf2Sols2 ((a1 : Nat), (a2 : Nat), (a3 : Nat)) ((b1 : Nat), (b2 : Nat), (b3 : Nat))
        (ta : Nat) (tb : Nat)).length ≠ 1) :=
  ⟨fun a1 a2 a3 b1 b2 b3 c1 c2 c3 t1 t2 t3 h =>
```

```fortran
! Yes_And_No_Twin.f90 · twin of Yes_And_No.lean, Between the Yes and the No, executed on finite charts.
! Build (sealed): gfortran -std=f2018 -O2 -fno-fast-math -ffp-contract=off Yes_And_No_Twin.f90
! Ten checks, each beside a control that must fail. Run plain, the ten checks pass and each control is shown to
! fail as it must: twenty lines, no failure. Run with the argument  control , each check runs with its defect
! planted and all ten lines are red.
! A bit is 0 or 1. A read of one bit is the pair (f(0), f(1)); the four reads are m = 0..3, f(0) = mod(m,2), f(1) = m/2.
! The Yes is m = 2, the No is m = 1.
!   I    the wall: for |A| = 1, 2, 3 and every e : A -> (A -> Bool), the diagonal g(a) = not e(a)(a) escapes the image;
!        the one-point type has no fixed-free endomorphism. Control: the diagonal without the negation.
!   II   reflection does not reach: for every forgetting record of size 1 to 3, every run misses a world.
!        Control: a record that keeps the side.
!   III  no third read: exactly two of the four reads are lossless, the Yes and the No, and they differ on each world.
!        Control: losslessness tested at one world only.
!   IV   the orientation is one bit: two lossless reads agree everywhere exactly when they agree at 0, and otherwise
!        one is the other turned. Control: the constant reads admitted.
!   V    what reveals is what cuts: on every forgetting record of size 1 to 3, a supply closes the gap, by some run on
!        record and supply, exactly when it is lossless. Control: a record that keeps the side.
!   VI   the gap is one bit and the wall is the No: the Yes closes every forgetting record, and the only read that
!        moves every point is the No. Control: a constant supply offered.
!   VII  the faithful repeat: among the lossless reads only the Yes says nothing new when said again; the No said twice
!        is the Yes; the Yes said 0 to 20 times returns the world. Control: repetition tested as return, f(f(w)) = w.
!   VIII clarity and satisfaction: on every forgetting record of size 1 to 3, a lossless supply makes the pair
!        (record, supply) separate the worlds, and every closing run says the same on what is held.
!        Control: a constant supply offered.
!   IX   the third axis is the lock: over GF(2) none of the 256 two-equation systems in three unknowns has exactly one
!        solution; on each of the 168 locked three-row systems, at all 8 targets, every two-row projection stays open;
!        and two eyes reading a forgetting record, through the Yes and the No, miss a world.
!        Control: solutions counted in two unknowns, the third axis dropped.
!   X    one and three before two: each of the 168 locked triads pins exactly one point at all 8 targets; a pair of
!        rows extends to a locked triad exactly when it is independent (42 ordered pairs); an independent pair leaves
!        exactly two points at all 4 targets. Control: dependent pairs admitted as independent.
program yes_and_no_twin
  implicit none
  integer :: checks, fails
  logical :: ctl
  character(len=32) :: arg
  checks = 0; fails = 0
  call get_command_argument(1, arg)
  ctl = (trim(arg) == 'control')
  if (ctl) write(*,'(a)') ' CONTROL FLAG SET: each check runs with its defect planted; every line below must be red'
  call pair('I: for |A| = 1 to 3 the diagonal escapes every e : A -> (A -> Bool); zero bits hold no wall', &
            'the diagonal without the negation', wall(.false.), wall(.true.))
  call pair('II: on every forgetting record of size 1 to 3 every run misses a world', &
            'a record that keeps the side', reflection(.false.), reflection(.true.))
  call pair('III: exactly two reads are lossless, the Yes and the No, and they differ on each world', &
            'losslessness tested at one world only', no_third(.false.), no_third(.true.))
  call pair('IV: lossless reads agree everywhere exactly when they agree at 0, else one is the other turned', &
            'the constant reads admitted', orientation(.false.), orientation(.true.))
  call pair('V: on every forgetting record a supply closes the gap exactly when it is lossless', &
            'a record that keeps the side', reveals(.false.), reveals(.true.))
  call pair('VI: the Yes closes every forgetting record, and the only read moving every point is the No', &
            'a constant supply offered', gap_one_bit(.false.), gap_one_bit(.true.))
  call pair('VII: only the Yes repeats faithfully; the No twice is the Yes; the Yes said 0 to 20 times returns the world', &
            'repetition tested as return', faithful(.false.), faithful(.true.))
  call pair('VIII: after a lossless cut the worlds never look alike, and every closing run says the same', &
            'a constant supply offered', clarity(.false.), clarity(.true.))
  call pair('IX: two axes never lock, the triad is irreducible, two eyes on the record miss a world', &
            'solutions counted in two unknowns', third_axis(.false.), third_axis(.true.))
  call pair('X: a locked triad pins one point, a pair is its shadow exactly when independent, and holds two', &
            'dependent pairs admitted', one_three_two(.false.), one_three_two(.true.))
  write(*,'(a,i0,a,i0,a)') ' BATTERY-JSON: {"checks":', checks, ',"failures":', fails, '}'
  if (fails > 0) error stop 1
contains
  subroutine check(label, ok)
    character(len=*), intent(in) :: label
    logical, intent(in) :: ok
    checks = checks + 1
    if (ok) then
      write(*,'(2a)') '  PASS  ', label
    else
      fails = fails + 1
      write(*,'(2a)') '  FAIL  ', label
    end if
  end subroutine check
  subroutine pair(label, defect, ok, okdef)
    character(len=*), intent(in) :: label, defect
    logical, intent(in) :: ok, okdef
    if (.not. ctl) then
      call check(label, ok)
      call check(label(1:index(label, ':')) // ' control, ' // defect // ': the check fails, as it must', .not. okdef)
    else
      call check(label(1:index(label, ':')) // ' [defect planted: ' // defect // '] ' // &
                 label(index(label, ':') + 2:), okdef)
    end if
  end subroutine pair

  ! the value of read m at bit w
  integer function rd(m, w)
    integer, intent(in) :: m, w
    if (w == 0) then
      rd = mod(m, 2)
    else
      rd = m / 2
    end if
  end function rd

  logical function lossless(m)
    integer, intent(in) :: m
    lossless = (rd(m, 0) /= rd(m, 1))
  end function lossless

  ! bit a of predicate p (a predicate on an n-point type is an integer 0 .. 2**n - 1)
  integer function bit(p, a)
    integer, intent(in) :: p, a
    bit = iand(ishft(p, -a), 1)
  end function bit

  ! I · the wall
  logical function wall(defect)
    logical, intent(in) :: defect
    integer :: n, np, total, code, a, g, k, e(0:2)
    logical :: hit
    wall = .true.
    do n = 1, 3
      np = 2**n; total = np**n
      do code = 0, total - 1
        k = code
        do a = 0, n - 1
          e(a) = mod(k, np); k = k / np
        end do
        g = 0
        do a = 0, n - 1
          if (defect) then
            g = g + bit(e(a), a) * 2**a
          else
            g = g + (1 - bit(e(a), a)) * 2**a
          end if
        end do
        hit = .false.
        do a = 0, n - 1
          if (e(a) == g) hit = .true.
        end do
        if (hit) wall = .false.
      end do
    end do
    ! the one-point type: count its endomorphisms that move every point; there must be none
    k = 0
    do g = 0, 0
      if (g /= 0) k = k + 1
    end do
    if (k /= 0) wall = .false.
  end function wall

  ! II · reflection on a forgetting record: r(0) = r(1) = 1; the control keeps the side, r(0) = 1, r(1) = 2
  logical function reflection(defect)
    logical, intent(in) :: defect
    integer :: sz, run, w, rw
    logical :: misses
    reflection = .true.
    do sz = 2, 3
      do run = 0, 2**sz - 1
        misses = .false.
        do w = 0, 1
          rw = 1
          if (defect .and. w == 1) rw = 2
          if (bit(run, rw - 1) /= w) misses = .true.
        end do
        if (.not. misses) reflection = .false.
      end do
    end do
    do run = 0, 1
      misses = .false.
      do w = 0, 1
        if (bit(run, 0) /= w) misses = .true.
      end do
      if (.not. misses .and. .not. defect) reflection = .false.
    end do
  end function reflection

  ! III · no third read
  logical function no_third(defect)
    logical, intent(in) :: defect
    integer :: m, cnt, w
    logical :: ok, sep
    cnt = 0; ok = .true.
    do m = 0, 3
      if (defect) then
        sep = (rd(m, 0) == 0)
      else
        sep = lossless(m)
      end if
      if (sep) then
        cnt = cnt + 1
        if (m /= 1 .and. m /= 2) ok = .false.
      end if
    end do
    do w = 0, 1
      if (rd(2, w) == rd(1, w)) ok = .false.
    end do
    no_third = ok .and. cnt == 2
  end function no_third

  ! IV · the orientation is one bit
  logical function orientation(defect)
    logical, intent(in) :: defect
    integer :: f, g, w
    logical :: same, turned
    orientation = .true.
    do f = 0, 3
      do g = 0, 3
        if (.not. defect .and. (.not. lossless(f) .or. .not. lossless(g))) cycle
        same = .true.; turned = .true.
        do w = 0, 1
          if (rd(f, w) /= rd(g, w)) same = .false.
          if (rd(f, w) /= 1 - rd(g, w)) turned = .false.
        end do
        if ((rd(f, 0) == rd(g, 0)) .neqv. same) orientation = .false.
        if (.not. (same .or. turned)) orientation = .false.
      end do
    end do
  end function orientation

  ! does some run on (record, supply) reach the value? record size sz, record of world w is rec(w)
  logical function closes(sz, rec0, rec1, s)
    integer, intent(in) :: sz, rec0, rec1, s
    integer :: run, w, idx
    logical :: good
    closes = .false.
    do run = 0, 2**(2 * sz) - 1
      good = .true.
      do w = 0, 1
        if (w == 0) then
          idx = (rec0 - 1) * 2 + rd(s, w)
        else
          idx = (rec1 - 1) * 2 + rd(s, w)
        end if
        if (bit(run, idx) /= w) good = .false.
      end do
      if (good) then
        closes = .true.
        return
      end if
    end do
  end function closes

  ! V · what reveals is what cuts
  logical function reveals(defect)
    logical, intent(in) :: defect
    integer :: sz, s, r1
    reveals = .true.
    do sz = 1, 3
      r1 = 1
      if (defect .and. sz >= 2) r1 = 2
      do s = 0, 3
        if (closes(sz, 1, r1, s) .neqv. lossless(s)) reveals = .false.
      end do
    end do
  end function reveals

  ! VI · the gap is one bit and the wall is the No
  logical function gap_one_bit(defect)
    logical, intent(in) :: defect
    integer :: sz, m, cnt, s
    gap_one_bit = .true.
    s = 2
    if (defect) s = 0
    do sz = 1, 3
      if (.not. closes(sz, 1, 1, s)) gap_one_bit = .false.
    end do
    cnt = 0
    do m = 0, 3
      if (rd(m, 0) /= 0 .and. rd(m, 1) /= 1) then
        cnt = cnt + 1
        if (m /= 1) gap_one_bit = .false.
      end if
    end do
    if (cnt /= 1) gap_one_bit = .false.
  end function gap_one_bit

  ! VII · the faithful repeat
  logical function faithful(defect)
    logical, intent(in) :: defect
    integer :: m, w, cnt, n, x
    logical :: rep
    faithful = .true.; cnt = 0
    do m = 0, 3
      if (.not. lossless(m)) cycle
      rep = .true.
      do w = 0, 1
        if (defect) then
          if (rd(m, rd(m, w)) /= w) rep = .false.
        else
          if (rd(m, rd(m, w)) /= rd(m, w)) rep = .false.
        end if
      end do
      if (rep) then
        cnt = cnt + 1
        if (m /= 2) faithful = .false.
      end if
    end do
    if (cnt /= 1) faithful = .false.
    do w = 0, 1
      if (rd(1, rd(1, w)) /= rd(2, w)) faithful = .false.
      do n = 0, 20
        x = w
        do m = 1, n
          x = rd(2, x)
        end do
        if (x /= w) faithful = .false.
      end do
    end do
  end function faithful

  ! VIII · clarity and satisfaction
  logical function clarity(defect)
    logical, intent(in) :: defect
    integer :: sz, s, run1, run2, w, idx
    logical :: good1, good2
    clarity = .true.
    do sz = 1, 3
      do s = 0, 3
        if (defect) then
          if (s /= 0) cycle
        else
          if (.not. lossless(s)) cycle
        end if
        ! the record is constant (value 1); the pair separates the worlds exactly when the supply differs
        if (rd(s, 0) == rd(s, 1)) clarity = .false.
        do run1 = 0, 2**(2 * sz) - 1
          good1 = .true.
          do w = 0, 1
            if (bit(run1, rd(s, w)) /= w) good1 = .false.
          end do
          if (.not. good1) cycle
          do run2 = 0, 2**(2 * sz) - 1
            good2 = .true.
            do w = 0, 1
              if (bit(run2, rd(s, w)) /= w) good2 = .false.
            end do
            if (.not. good2) cycle
            do w = 0, 1
              idx = rd(s, w)
              if (bit(run1, idx) /= bit(run2, idx)) clarity = .false.
            end do
          end do
        end do
      end do
    end do
  end function clarity

  ! solutions of rows ra, rb at targets ta, tb, over three unknowns, or over two with the third fixed at 0
  integer function nsol2(ra, rb, ta, tb, two)
    integer, intent(in) :: ra(3), rb(3), ta, tb
    logical, intent(in) :: two
    integer :: v, x(3)
    nsol2 = 0
    do v = 0, 7
      x(1) = v / 4; x(2) = mod(v / 2, 2); x(3) = mod(v, 2)
      if (two .and. x(3) /= 0) cycle
      if (mod(dot_product(ra, x), 2) == ta .and. mod(dot_product(rb, x), 2) == tb) nsol2 = nsol2 + 1
    end do
  end function nsol2

  integer function det3gf2(a, b, c)
    integer, intent(in) :: a(3), b(3), c(3)
    det3gf2 = modulo(a(1) * (b(2) * c(3) - b(3) * c(2)) - a(2) * (b(1) * c(3) - b(3) * c(1)) &
                     + a(3) * (b(1) * c(2) - b(2) * c(1)), 2)
  end function det3gf2

  ! IX · the third axis is the lock
  logical function third_axis(defect)
    logical, intent(in) :: defect
    integer :: code, a(3), b(3), c(3), t(3), k, locked, sz, q, run, w, y
    logical :: misses
    third_axis = .true.
    do code = 0, 255
      k = code
      a(1) = mod(k, 2); k = k / 2; a(2) = mod(k, 2); k = k / 2; a(3) = mod(k, 2); k = k / 2
      b(1) = mod(k, 2); k = k / 2; b(2) = mod(k, 2); k = k / 2; b(3) = mod(k, 2); k = k / 2
      t(1) = mod(k, 2); k = k / 2; t(2) = mod(k, 2)
      if (nsol2(a, b, t(1), t(2), defect) == 1) third_axis = .false.
    end do
    locked = 0
    do code = 0, 511
      k = code
      a(1) = mod(k, 2); k = k / 2; a(2) = mod(k, 2); k = k / 2; a(3) = mod(k, 2); k = k / 2
      b(1) = mod(k, 2); k = k / 2; b(2) = mod(k, 2); k = k / 2; b(3) = mod(k, 2); k = k / 2
      c(1) = mod(k, 2); k = k / 2; c(2) = mod(k, 2); k = k / 2; c(3) = mod(k, 2)
      if (det3gf2(a, b, c) /= 1) cycle
      locked = locked + 1
      do k = 0, 7
        t(1) = k / 4; t(2) = mod(k / 2, 2); t(3) = mod(k, 2)
        if (nsol2(a, b, t(1), t(2), defect) == 1) third_axis = .false.
        if (nsol2(a, c, t(1), t(3), defect) == 1) third_axis = .false.
        if (nsol2(b, c, t(2), t(3), defect) == 1) third_axis = .false.
      end do
    end do
    if (locked /= 168) third_axis = .false.
    ! two eyes on a forgetting record (constant record, so q reads one value y for both worlds)
    do sz = 1, 3
      do q = 0, 2**sz - 1
        y = bit(q, 0)
        do run = 0, 15
          misses = .false.
          do w = 0, 1
            if (bit(run, rd(2, y) * 2 + rd(1, y)) /= w) misses = .true.
          end do
          if (.not. misses) third_axis = .false.
        end do
      end do
    end do
  end function third_axis

  ! solutions of a three-row system at target t
  integer function nsol3(a, b, c, t)
    integer, intent(in) :: a(3), b(3), c(3), t(3)
    integer :: v, x(3)
    nsol3 = 0
    do v = 0, 7
      x(1) = v / 4; x(2) = mod(v / 2, 2); x(3) = mod(v, 2)
      if (mod(dot_product(a, x), 2) == t(1) .and. mod(dot_product(b, x), 2) == t(2) .and. &
          mod(dot_product(c, x), 2) == t(3)) nsol3 = nsol3 + 1
    end do
  end function nsol3

  ! X · one and three before two
  logical function one_three_two(defect)
    logical, intent(in) :: defect
    integer :: ia, ib, ic, a(3), b(3), c(3), t(3), k, locked, indep, ext
    logical :: ind
    one_three_two = .true.; locked = 0; indep = 0
    do ia = 0, 7
      a(1) = ia / 4; a(2) = mod(ia / 2, 2); a(3) = mod(ia, 2)
      do ib = 0, 7
        b(1) = ib / 4; b(2) = mod(ib / 2, 2); b(3) = mod(ib, 2)
        ind = (ia /= 0 .and. ib /= 0 .and. ia /= ib)
        if (defect .and. ia == ib .and. ia /= 0) ind = .true.
        ext = 0
        do ic = 0, 7
          c(1) = ic / 4; c(2) = mod(ic / 2, 2); c(3) = mod(ic, 2)
          if (det3gf2(a, b, c) == 1) then
            ext = ext + 1
            if (.not. defect) then
              locked = locked + 1
              do k = 0, 7
                t(1) = k / 4; t(2) = mod(k / 2, 2); t(3) = mod(k, 2)
                if (nsol3(a, b, c, t) /= 1) one_three_two = .false.
              end do
            end if
          end if
        end do
        if ((ext /= 0) .neqv. ind) one_three_two = .false.
        if (ind) then
          indep = indep + 1
          do k = 0, 3
            if (nsol2(a, b, k / 2, mod(k, 2), .false.) /= 2) one_three_two = .false.
          end do
        end if
      end do
    end do
    if (.not. defect .and. locked /= 168) one_three_two = .false.
    if (indep /= 42) one_three_two = .false.
  end function one_three_two
end program yes_and_no_twin
```
