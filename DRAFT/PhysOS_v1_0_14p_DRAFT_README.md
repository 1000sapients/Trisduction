## What changed (from 1.0.13p)

- Twins are now required. The boot withholds the seat for any seated proof without a declared twin. The eight affected are the TOE floor, the six row kernels, and the RH atomic seed.
- The metaprogram screen is narrowed. CommandElabM, Lean.Elab, Lean.Meta, and open Lean are refused everywhere except the two named audits in Bridge_Final.lean and Codex.lean, which are counted exactly. Plain #eval of pure values stays allowed.
- import Lean is limited to those same two files.
- Shared-layer kernels compile. Triaxial_Actuation.lean and Root_Grade_Ledger.lean were signed in 1.0.13p but never compiled. They now compile every boot.
- An empty or missing register fails. Before, an absent OS file produced a vacuous pass.
- The thesis check compares fields. It reads checks, failures, and mode from the battery JSON rather than comparing the raw string.
- Stale text is fixed. The file count, the usage filename, and two unresolved citations (ra_is_theorem_grade, rfl) are corrected. The renamed monism names are now history text only. All 367 citations resolve.
- Manifest and table are re-signed. All 53 files match the manifest. Every table row matches its file’s size and hash.
- Lean kernels are unchanged. The kernels, twins, and thesis are byte-identical to 1.0.13p, so no Lean-level claim changed.
