# Scribe Handouts

Standing rules for every scribe working in this repository. Each handout is binding where it applies; the root file `SCRIBE_REMINDERS.md` lists them in one place.

| Handout | Binds | Recorded |
|---|---|---|
| [Two_Layer_Rule.md](Two_Layer_Rule.md) | Every paper in which the Root Axiom stands anywhere in the arc: the floor proved, the reading posited; never water down a premise-grade proof, never inflate it | 2026-10-05 |
| [Pre_Installed_Toolchain.md](Pre_Installed_Toolchain.md) | Every scribe who compiles Lean or Fortran: use Lean 4.19.0, Mathlib v4.19.0 and gfortran at `/root/toolchain`, never reinstall them | 2026-10-21 |
