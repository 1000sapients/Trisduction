# 3. Montgomery's Pair Correlation

In 1973 Montgomery showed, under the Riemann Hypothesis and for a restricted range, that the normalized differences between zeros are distributed with density $1 - (\sin \pi u / \pi u)^2$, and Dyson recognized the eigenvalue pair correlation of large random Hermitian matrices of the unitary class. Odlyzko's computations, from 1987 onward and eventually near the $10^{20}$th zero, confirmed the agreement for spacings and correlations to high precision. The zeros repel each other as eigenvalues of a unitary-class system do. Row 23a asks for the full-range law; the restricted range is the certified part.

# 4. Two Classes and One Symmetry Between Them

A two-level Hermitian block has diagonal entries $a$ and $d$ and off-diagonal entry $b + ic$. Time reversal acts on it as complex conjugation, sending $c$ to $-c$; it is an involution (`T_involution`), and its fixed set is exactly the real blocks, $c = 0$ (`T_fixed_iff_real`). Systems that keep time reversal live on that fixed set and form the orthogonal class; systems that break it leave the set and form the unitary class. A magnetic, time-odd term is precisely an entry $c \neq 0$, and it breaks time reversal (`magnetic_term_breaks_T`). Written as a Hamiltonian, $H = H_0 + \lambda V_{\mathrm{mag}}$ with $H_0$ real and $V_{\mathrm{mag}}$ the time-odd term, time reversal fixes $H$ exactly when $\lambda = 0$ (`perturbation_breaks_T`). The template's seat appears here again: a reflection, its fixed set, and the question which side of it a spectrum lives on.

# 5. Level Repulsion Counts Conditions

Two levels of the block coincide exactly when its discriminant $(a-d)^2 + 4(b^2 + c^2)$ vanishes. On the real blocks that takes two conditions, $a = d$ and $b = 0$ (`degenerate_real_two_conditions`); on the complex blocks it takes three, $a = d$, $b = 0$ and $c = 0$ (`degenerate_iff`, proved for every integer entry by the sum-of-squares argument that holds over the reals, and checked on a grid by exhaustion in `degenerate_iff_three_conditions`). The probability of a small spacing $s$ scales as $s$ to the power of the codimension minus one: $s^1$ for the orthogonal class and $s^2$ for the unitary class (`repulsion_exponents`). Breaking time reversal adds one condition, and one more power of repulsion: the magnetic term buys the zeros' stronger repulsion.

  function rnd() result(r)
    real(dp) :: r
    seed = mod(16807_8*seed, 2147483647_8)
    r = (real(seed, dp) + 0.5_dp) / 2147483647.0_dp
  end function rnd
  function gauss() result(g)
    real(dp) :: g
    g = sqrt(-2.0_dp*log(rnd())) * cos(2.0_dp*PI*rnd())
  end function gauss
  function chi(k) result(c)
    integer, intent(in) :: k
    real(dp) :: c
    integer :: q
    c = 0.0_dp
    do q = 1, k

    end do

      p = p + (32.0_dp/PI**2)*x*x*exp(-4.0_dp*x*x/PI)*dx

      q = d(i) - x - e2(i)/q

    end do

        end if

    real(dp), intent(out) :: v, f

    allocate(pool(N*M)); pool = reshape(all, [N*M]); call shellsort(pool)
    sm = 0.0_dp; ss = 0.0_dp; ns = 0; nsm = 0
    do j = 1, M
      do k = 1, N
        lo = 1; hi = N*M                                 ! rank by binary search
        do while (lo < hi)
          mid = (lo + hi)/2
          if (pool(mid) < all(k,j)) then
            lo = mid + 1
          else
            hi = mid
          end if
        end do
        u(k) = real(lo, dp) / real(M, dp)                ! unfolded: mean spacing one
      end do
      do k = N/4, 3*N/4 - 1
        s = u(k+1) - u(k)
        sm = sm + s; ss = ss + s*s; ns = ns + 1
        if (s < 0.1_dp) nsm = nsm + 1
      end do
    end do
    sm = sm/ns; v = ss/ns - sm*sm; v = v/(sm*sm); f = real(nsm,dp)/real(ns,dp)
  end subroutine stats
  subroutine ensemble(beta, v, f)
    integer, intent(in) :: beta
    real(dp), intent(out) :: v, f
    real(dp) :: d(N), e2(N), lam(N)
    real(dp), allocatable :: all(:,:)

    allocate(all(N, M))
    do j = 1, M
      e2(1) = 0.0_dp
      do k = 1, N
        d(k) = sqrt(2.0_dp)*gauss()
        if (k > 1) e2(k) = chi(beta*(N - k + 1))**2
      end do
      call eigs(d, e2, lam)
      all(:, j) = lam
    end do
    call stats(all, v, f)
  end subroutine ensemble
  subroutine poisson(v, f)
    real(dp), intent(out) :: v, f
    real(dp), allocatable :: all(:,:)
    real(dp) :: x(N)
    integer :: j, k
    allocate(all(N, M))
    do j = 1, M
      do k = 1, N
        x(k) = rnd()
      end do
      call shellsort(x)
      all(:, j) = x
    end do
    call stats(all, v, f)
  end subroutine poisson
  subroutine shellsort(a)
    real(dp), intent(inout) :: a(:)
    integer :: gap, i, j, n
    real(dp) :: t
    n = size(a); gap = n/2
    do while (gap > 0)
      do i = gap + 1, n
        t = a(i); j = i
        do while (j > gap)
          if (a(j - gap) <= t) exit
          a(j) = a(j - gap); j = j - gap
        end do
        a(j) = t
      end do
      gap = gap/2
    end do
  end subroutine shellsort

    end if
  end subroutine check
